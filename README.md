# MAX Chat на GREEN-API

Минималистичный адаптивный веб-чат на React для отправки и получения текстовых сообщений MAX через GREEN-API.

## Возможности

- Подключение по `idInstance`, `apiTokenInstance` и адресу API.
- Создание чата по номеру телефона в международном формате.
- Отправка текстовых сообщений через `sendMessage`.
- Получение входящих уведомлений через `receiveNotification` с подтверждением `deleteNotification`.
- Список чатов, поиск по списку, счётчик непрочитанных, статусы отправки.
- Адаптивная раскладка для мобильных экранов.
- Данные API не сохраняются: они живут только в памяти вкладки.

## Требования

Node.js 20.19+ или 22.12+ и npm.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте адрес, указанный Vite (обычно `http://localhost:5173`). Для production-сборки выполните `npm run build`, для локального просмотра сборки — `npm run preview`.

## Подключение

1. Создайте и авторизуйте инстанс MAX в [личном кабинете GREEN-API](https://console.green-api.com).
2. В чате нажмите значок настроек и введите `idInstance`, `apiTokenInstance` и базовый адрес API инстанса (по умолчанию `https://api.green-api.com`).
3. Нажмите «Подключиться». Для получения входящих сообщений в настройках инстанса должен быть включён `incomingWebhook`, а `webhookUrl` оставлен пустым (технология HTTP API).
4. Создайте чат и введите номер получателя в международном формате, например `79991234567`.
5. Отправляйте и получайте текстовые сообщения.

## Примечания

- Адреса API должны разрешать запросы с origin сайта (CORS). Если браузер блокирует запросы, используйте предоставленный GREEN-API адрес/кластер или настройте собственный reverse proxy.
- Токен вводится в интерфейсе и не сохраняется после закрытия вкладки. Для публичного production-приложения секреты следует держать на сервере и вызывать GREEN-API через backend.
- Получение уведомлений реализовано последовательным опросом очереди. Уведомление подтверждается вызовом `deleteNotification` после обработки.
- Интерфейс обрабатывает только текстовые входящие сообщения, согласно условиям тестового задания.
